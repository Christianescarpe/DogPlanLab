<AnswerFirstSummary>
  Coat type is the deciding factor — a slicker brush suits most medium-to-long or double coats, a bristle brush suits short and smooth coats, and a specialized undercoat rake or deshedding tool is only necessary for genuinely heavy-shedding double-coated breeds.
</AnswerFirstSummary>

## How to Choose

This is for anyone starting the brushing routine described in existing [Brushing](/puppy-handling/brushing/). Match to coat type first, price or brand second; consider handle comfort for frequent use, pin or bristle spacing appropriate to coat density, and a detangling comb as a companion tool for longer coats prone to matting.

## Comparison

| Coat type | Brush type |
|---|---|
| Short, smooth | Soft bristle brush or grooming mitt |
| Medium or long, single coat | Slicker brush |
| Double coat, heavy shedding | Slicker brush + undercoat rake |
| Curly or wire coat | Slicker brush + detangling comb |

## Best For / Not Ideal For

A heavy-duty undercoat rake is not necessary — and can be uncomfortable — for a short, smooth-coated puppy with no undercoat to speak of.

## FAQ

**Do I need multiple brushes?** Many double-coated dogs benefit from both a slicker brush and an undercoat rake used for different purposes; single-coated puppies typically don't need more than one primary brush.

## Common Mistakes

- Choosing a brush by price or appearance instead of coat type.
- Using an undercoat rake on a coat without an undercoat.
- Skipping a detangling comb for a longer coat prone to matting.

## Safety and Behavior Red Flags

Introduce any new brush gradually per existing [Brushing](/puppy-handling/brushing/)'s comfort-building method; stop if you notice skin irritation and check for an underlying cause before continuing.
